# ⚽ サッカーコーチノート チーム共有版（ConoHa WING対応）

ログインして使う**サーバー共有バージョン**です。作成した練習メニュー・ドリル・戦術ボード・ポジション表・スケジュール・出欠がサーバーに保存され、**登録したメンバー全員で共有**されます。

- メールアドレス＋パスワード、または **Googleアカウント** でログイン
- **パスワード再設定**（メールでリセットリンクを送信）に対応
- 新規登録には**招待コード**（config.phpで設定）が必要
- 変更は自動保存され、他のメンバーの変更も約20秒ごとに自動反映
- UI・機能はオフライン版と共通（PNG保存・JSON書き出し・印刷もそのまま使えます）

### 権限（コーチ／プレイヤー）

| 区分 | できること |
|------|-----------|
| **コーチ** | すべての機能（メニュー・ドリル・戦術・ポジション・スケジュール・名簿の作成/編集/削除、データ読込/初期化） |
| **プレイヤー** | すべての内容の**閲覧**と、スケジュールでの**自分の出欠の回答**のみ |

- コーチ用とプレイヤー用で**別々の招待コード**を設定できます（`config.php`）。
- プレイヤーは登録時に**学年**も入力し、自動的にチームの名簿（メンバー）に追加されます。
- 権限はサーバー側でも検証され、プレイヤーは自分の出欠以外を書き換えられません。

## 動作要件

- PHP 7.4以上（PHP 8.x推奨）＋ PDO（SQLite または MySQL）＋ curl
- ConoHa WING はすべて標準で対応しています

## ConoHa WING への設置手順

### 1. ファイルをアップロード

リポジトリの**全ファイル**を `public_html/`（または任意のサブディレクトリ）にアップロードします。

- ConoHa WING コントロールパネル →「サイト管理」→「ファイルマネージャー」、または FTP/SFTP
- `index.html`・`css/`・`js/`・`team/` がすべて必要です（team版は共通のUIファイルを参照します）

### 2. 設定ファイルを作成

`team/config.sample.php` を複製して `team/config.php` にリネームし、編集します。

```php
'invite_code'        => 'コーチ用の合言葉',      // ★必ず変更してください（コーチ登録用）
'player_invite_code' => 'プレイヤー用の合言葉',  // 選手・保護者の登録用（''で自己登録オフ）
```

コーチ用とプレイヤー用は別のコードにして、コーチ用コードは限られた人にだけ伝えてください。
（`coach_invite_code` を明示設定してもOK。未設定なら `invite_code` がコーチ用として使われます。）

### 3. アクセスして動作確認

`https://あなたのドメイン/team/` を開くとログイン画面が表示されます。
「新規登録」からお名前・メールアドレス・パスワード・招待コードで登録するとすぐ使えます。

データベースは標準で **SQLite**（`team/data/app.db` に自動作成、設定不要）。
`team/data/` には `.htaccess` が自動設置され、Webから直接読めないよう保護されます。

> 💡 ConoHa WINGの無料独自SSL（HTTPS）を必ず有効にしてください。

### 4. MySQLを使う場合（任意）

ConoHa WING コントロールパネル →「サイト管理」→「データベース」で DB とユーザーを作成し、`config.php` を書き換えます。

```php
'db' => [
  'driver' => 'mysql',
  'mysql' => [
    'host'    => 'mysqlXXXX.conoha.ne.jp', // DBサーバー名
    'dbname'  => '作成したDB名',
    'user'    => '作成したユーザー名',
    'pass'    => 'パスワード',
    'charset' => 'utf8mb4',
  ],
],
```

テーブルは初回アクセス時に自動作成されます。

### 5. Googleログインを有効にする場合（任意）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「OAuth同意画面」を設定（外部／アプリ名など最低限でOK）
3. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は**ウェブアプリケーション**
4. **承認済みのリダイレクトURI**に次を登録：
   ```
   https://あなたのドメイン/team/auth_google.php
   ```
5. 発行された クライアントID／クライアントシークレット を `config.php` に貼り付け：
   ```php
   'google' => [
     'client_id'     => 'xxxxx.apps.googleusercontent.com',
     'client_secret' => 'GOCSPX-xxxxx',
   ],
   ```

設定するとログイン画面に「Googleでログイン」ボタンが表示されます。
Googleで初めてログインするメンバーにも区分・招待コードの入力を求めるので、部外者は参加できません。

### 6. パスワード再設定メール（任意）

`config.php` の `mail` を設定すると、ログイン画面の「パスワードをお忘れですか？」から
再設定リンクをメール送信できます（ConoHa WING は標準の PHP `mail()` が使えます）。

```php
'mail' => [
  'enabled'   => true,
  'from'      => 'no-reply@あなたのドメイン', // 独自ドメインのアドレス推奨
  'from_name' => 'サッカーコーチノート',
],
```

`enabled` を `false` にすると再設定メールを送りません。迷惑メール扱いを避けるため、
送信元は独自ドメインのアドレスにすることをおすすめします。

## データの共有のしくみ

- 登録メンバー全員が**同じ1つのチームデータ**（ドリル・メニュー・ボード・ポジション表・スケジュール・名簿・出欠）を見ます
- 編集は項目ごとの差分としてサーバーに保存（最後に保存した内容が有効）
- プレイヤーは閲覧のみ。ただしスケジュールで**自分の出欠**だけは回答でき、サーバー側でも権限を検証します
- 「データ」タブの JSON 書き出し／読み込みはチーム全体のデータに対して動作します（読み込み・全削除はコーチのみ・全員に影響するため注意）

## ファイル構成

```
team/
├── index.php          アプリ画面（要ログイン。../index.html を共通UIとして配信）
├── login.php          ログイン・新規登録（区分/学年/招待コード）
├── logout.php         ログアウト
├── auth_google.php    Google OAuth 2.0 ログイン
├── forgot.php         パスワード再設定リクエスト（メール送信）
├── reset.php          パスワード再設定（新パスワード入力）
├── api/data.php       データ共有API（差分同期・権限チェック）
├── js/remote.js       サーバー同期エンジン（自動保存・自動反映）
├── inc/               共通処理（設定・DB・認証・メール）
├── config.sample.php  設定ファイルのひな形 → config.php にコピーして使用
└── data/              SQLiteデータベース（自動作成・Webアクセス遮断）
```
