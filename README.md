# ⚽ サッカーコーチノート

年中（4〜5歳）から小学生までのサッカーチームのコーチが、**タブレットで練習メニューや戦術を作成・説明する**ためのWebアプリです。

## 2つのバージョン

| | 使い方 | データ保存先 |
|---|---|---|
| **スタンドアロン版**（このページ） | ブラウザで `index.html` を開くだけ。インストール・ビルド・サーバー不要 | 端末内（localStorage） |
| **チーム共有版**（[`team/`](team/README.md)） | ConoHa WING等のPHPサーバーに設置。Googleアカウントまたはメールアドレスでログイン。コーチ／プレイヤーの権限あり | サーバー（登録メンバー全員で共有） |

チーム共有版のセットアップ手順は **[team/README.md](team/README.md)** を参照してください。UI・機能は両バージョン共通です。

## 主な機能

### 📋 練習メニュー作成
- ドリル集から練習を選んで、その日のメニューを組み立て（時間・メモ付き、合計時間を自動計算）
- 休憩などの自由項目も追加可能
- 入力は自動保存

### 🏃 ドリル集（練習の引き出し）
- カテゴリ（ウォーミングアップ／ドリブル／パス／シュート…）、対象年齢（U-6〜U-12）、時間、人数、用具、やり方、コーチングポイントを登録
- 戦術ボードで描いた図をドリルに添付可能

### 🧠 戦術ボード
- タッチ操作でコート上に「味方・相手・ボール・コーン・マーカー・ミニゴール」を配置
- 矢印（動き）・点線矢印（パス）・フリーハンドペン・文字入れ・色選択
- 駒はドラッグで移動、タップで番号や名前を変更
- コートは「全面（横／縦）・ハーフ・フリースペース」から選択
- 元に戻す（Undo）対応

### 🧩 ポジション（フォーメーション）
- 5人制（園児向け）・**8人制（小学生公式）**・11人制のテンプレート（3-3-1、2-4-1 など）
- 選手をドラッグで配置調整。枠をタップすると**登録メンバーから選んで割り当て**（自由入力も可）
- 各枠の**役割（GK・DF・MF・FW）と背番号**も自由に設定可能
- ポジション表（番号・役割・名前の一覧）付きで印刷可能

### 📅 スケジュール（練習・試合・出欠・結果）
- 練習／試合／その他の予定を日時・場所・対戦相手・練習メニュー付きで登録
- 予定の**コピー**（内容を引き継いで別日に複製）、**複数日まとめて登録**（毎週・隔週・毎日 × 回数）に対応
- メンバーごとの**参加状況（出席・欠席・未定）**を記録、集計を自動表示
- 試合の**結果（スコア・振り返りメモ）**を記録
- 予定一覧・出欠表・結果を印刷、JSONでも書き出し

### 👥 メンバー（名簿）
- 選手を**名前・学年・背番号・メモ**で登録
- 名簿を印刷でき、スケジュールの出欠と連動
- **CSVで書き出し／読み込み**（Excel対応・BOM付き）。表計算ソフトでまとめて編集して取り込めます

### 💾 データ出力・印刷配布
- **JSON書き出し／読み込み**：全データまたは練習メニュー単体をファイル出力。別のタブレットへの引き継ぎ・共有が可能
- **PNG保存**：戦術ボード・フォーメーション図を画像として保存
- **印刷**：練習メニュー（図・やり方・ポイント入りのA4配布資料）、戦術ボード、ポジション表を印刷レイアウトで出力。ブラウザの印刷ダイアログからPDF保存も可能

## 使い方

1. `index.html` をブラウザ（Safari / Chrome など）で開く
2. タブレットのホーム画面に追加すると、アプリのように全画面で使えます
3. データは端末のブラウザ内（localStorage）に自動保存されます

> 💡 GitHub Pages などで公開すると、URLを開くだけでどのタブレットからも利用できます。
> （リポジトリ設定 → Pages → ブランチを選択して公開）

初回起動時にはサンプルのドリル・メニュー・ボード・フォーメーションが入っています。「データ」タブから初期化・書き出し・読み込みができます。

## 技術構成

- 純粋な HTML / CSS / JavaScript（フレームワーク・ビルド不要）
- 図はすべて SVG 描画（きれいに印刷・PNG化できます）
- タッチ操作は Pointer Events 対応（iPad / Android タブレット / PC）

```
index.html      … 画面
css/style.css   … スタイル（画面用＋印刷用）
js/board.js     … 戦術ボード描画エンジン（SVG）
js/app.js       … アプリ本体（メニュー・ドリル・ポジション・データ管理）
```
